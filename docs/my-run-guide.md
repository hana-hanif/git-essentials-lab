# Run Guide

## Prerequisites

- **Python 3.9 or newer**
- **JDK 17 or newer**
- **Git 2.23 or newer**
- **A GitHub account**
- **Terminal and text editor**

## Run the demo

```bash
python3 run.py demo
```

## What the demo does

The demo is about library loan using a fixed date. It:

- Prints the loan limits
- Searches the catalog for git and prints the results.
- Lends Git Essentials to Alex with a due date
- Prints the return fee
- Prints the number of active loans remaining
